# Insightra UI / UX 规范 v2

状态：用户已确认视觉方向；作为后续开发基线。

## 产品结构

主导航：概览、金融资产、数据研究、知识空间、健康记录、家庭环境。
辅助导航：数据管理、数据连接、保存的视图、外观与布局。
数据研究按对象组织：研究项目、数据集、实验记录；产业网络属于工作视图。
因子挖掘、分析验证、策略回测是研究活动或实验类型，不再以五个巨大流程入口组织页面。正式执行能力尚未接入。

主导航回答“在哪个数据领域”，二级导航回答“正在做什么”。不要把具体图表、算法或配置项混入主导航。

## 视觉语言

- 三主题共用布局、字体、间距和交互语义，仅改变颜色变量。
- 默认中性浅色；纸感暖白适合阅读，石墨深色适合夜间。禁止新页面硬编码白底或黑字。
- 使用 `--bg`、`--surface`、`--soft`、`--ink`、`--muted`、`--border`、`--accent` 等变量。
- 图表系列使用 `--chart-blue / purple / green / warm / red`；颜色的业务含义跨页面保持一致。
- 圆角以 5–9px 为主。主页面用细边界组织结构，不用大阴影、渐变背景和过量装饰卡片。
- 阴影仅用于浮层。图表优先获得空间；统计摘要必须对当前任务有用。
- 新模块正文 12–14px、辅助说明 11–12px、模块标题 17–20px、页面标题 23–27px。10px 只用于非关键图例与编号。
- 中文优先使用系统无衬线字体；界面不依赖外部字体 CDN。数值采用等宽数字，代码使用等宽字体。
- 舒适与紧凑密度只调整留白、行高和面板间距，不通过缩小正文制造密度。

## 页面骨架

概览采用连续的编辑式版面：市场走势为主区，研究和知识形成侧区与下区，家庭布局和健康入口共同组成生活区域。使用主次比例、不同排版和共享分隔线建立整体感；不再将所有模块塞进等大的卡片。
研究工作台使用紧凑页头、资源侧栏、列表与按需详情，优先展示真实项目、数据状态和输入输出，不以虚构绩效图装饰空项目。

1. 固定的导航和工作区上下文。
2. 简短页面标题、说明及最多一个主要操作。
3. 必要的任务切换、时间范围、对象选择与数据状态。
4. 主画布或主要内容，占用最多空间。
5. 按需打开的对象详情与来源证据。

同类页面共用 `.surface-box`、`.box-heading`、`.data-table`、`.status-pill`、`.message`。
高信息密度页面避免把所有内容拆成孤立卡片。表格优先用行分隔，图表不嵌套多重边框。

## 数据可信度

- 真实数据标明来源、日期/区间、单位、口径和获取时间。
- 缓存标明缓存状态，超过 24 小时的行情缓存标明过期，不静默当成最新值。
- 金融日线明确“非实时”和复权口径；未导入持仓时不展示虚构资产总额。
- 示例必须在视图顶部就能识别；所有示例数值不得进入真实数据表。
- 健康记录、家庭示例可切回“我的数据”的真实空状态。
- 缺失值与零不同；未接入与故障不同；请求成功与权限完整不同。
- 披露事实、推断、研究笔记与未核验记录分别表达，颜色之外还需文字或线型。
- 图中的位置、面积、线宽若不编码真实量值，必须避免暗示或说明其示意性质。

## 交互规范

- 操作使用真实 button、input、select，保留可见键盘焦点。
- 选择、悬停、过滤是不同状态；悬停不得覆盖已选择对象。
- 同一研究对象跨视图保持选择；更改参数时明确结果是否已重新计算。
- 异步请求显示加载；禁用重复提交；旧请求不能覆盖新选择。
- 成功使用轻量通知，错误保留原因与可执行的重试入口。不能只弹一次后隐藏错误。
- 空状态解释缺失内容，并提供合理下一步；不假装正在计算。
- 删除本地文档需在界面明确确认，同时说明会删除分块。
- 弹窗进入时管理焦点，Tab 不离开弹窗，Escape 关闭，关闭后恢复触发按钮焦点。
- 主要信息不能只存在于 hover tooltip。图表提供数据表作为辅助读取方式。
- 配置页面仅显示“已配置”与掩码；输入留空保留原值，提交完成清空输入。

## 可视化准则

- 产业：默认主视图必须显示全行业公司的真实连接；社群只作为背景区域，不能代替公司节点。选中公司强调上下游方向，保留其他公司的整体上下文。公司位置不随搜索、选中、指标或未来行情帧改变。
- 节点大小可编码连接广度或桥接中心性，必须给出计算口径和资料覆盖局限。不能直接把结构指标称为投资价值或产业控制力。
- 规模扩大后采用分层聚合、逐级展开、选择邻域、标签避让与稳定布局；不让所有节点同时竞争注意力。
- 时序：坐标、单位、时间口径可见；日线按交易日等距排列时说明。多序列共用量纲，明确基准。
- 因子：相关矩阵对称，颜色编码正负与强度；示例 IC 不被描述为真实绩效。
- 知识：合成语义地图明确标注；真实文档分块按文件和顺序排列，不冒充向量投影。
- 家庭：示意平面图允许选择空间；温度、湿度、空气质量独立标注单位。设备未接入不显示在线。
- 尊重 `prefers-reduced-motion`；不加入无用途的持续动画。

## 响应式与验收

- 桌面优先保留主画布 + 详情；宽度不足时详情移至下方。
- 手机主导航抽屉化，工具栏换行或局部横向滚动；页面整体不能横向溢出。
- 表格和大型地图可局部滚动，但要保留提示与可访问的替代视图。
- 输入框在触屏下不缩小至 16px 以下；主要触屏操作目标尽量达到 40–44px。
- 每个新模块检查中性、纸感、深色主题，以及至少 1440px 和 390px 宽度。
- 验收包含正常、加载、空、错误、未配置状态；检查键盘操作和浏览器控制台。

## 家庭布局编辑

- 浏览和编辑模式明确区分；环境读数仍标注示例，布局本身可真实保存。
- 当前用矩形房间建模，单位为米，拖动按 0.1 m 对齐；房间尺寸也能通过数值输入修改。
- 房间移动时家具一起移动，家具坐标相对所属房间。房间不能重叠，家具不能超出房间。
- 缩放手柄在最上层，避免被相邻房间或家具遮挡。数值输入提供等价键盘操作。
- 选中房间的边缘与尺寸标注放在独立覆盖层，在所有房间和家具绘制之后呈现。覆盖层不捕获指针；缩放手柄继续位于其上。
- 编辑支持撤销/重做、取消、明确保存。未保存草稿暂存浏览器，正式布局写入 SQLite。
- 删除房间明确提示其家具也会删除。实体家具之间不能重叠；地毯允许叠放。
- 拖动采用独立浮层：房间和其家具一起移至最上层，原位置以虚线保留，落点轮廓表示实际候选坐标。提起时略微上移、放大并添加阴影；非法落点使用红色边缘和阴影，不能只依赖文字提示。
- 拖动预览不修改正式布局或写入草稿；合法松手只产生一次可撤销修改，非法松手、Escape 或 pointercancel 保持拖动前的位置。尊重减少动态效果设置。
- 当前画布 20 × 14 m，最多 30 个房间、200 件家具；暂不支持任意多边形墙体和多楼层。

## 结构化数据编辑

- 数据管理和文档知识库分别管理结构化记录与文本资料。导入入口说明支持 JSON、CSV、TSV、JSONL。
- 对象数组以分页表格编辑；嵌套结构以可折叠 JSON 树编辑；源码是辅助视图，不能替代可视化编辑。
- JSON 保留数字、布尔、null、数组和对象类型；CSV/TSV 默认保留文本，不能擅自把证券代码的前导零删掉。
- 显示保存状态和版本号；版本冲突必须阻止覆盖。错误不能被展示成保存成功。
- 导出以已保存版本为准；CSV/TSV 的嵌套值作为 JSON 文本导出，并提示这一口径。
- 产业资料保存时校验引用与证据标记。公开披露/推断沿用资料来源，不因接入平台而变成已核实结论。

## 健康记录视觉语言

采用长期趋势、24 小时睡眠占比和可选择的每日记录组成连续日志，避免重复的指标卡片加普通折线图。变化值仅描述样本，不提供虚构的健康评分。个人数据未接入时明确显示示例或空状态。

## 市场小组件与三层入口

1. 数据管理 → 数据源：选择适配器并同步，查看进度、日期、字段、覆盖范围及失败原因；同步结果进入数据集。
2. 小组件库：声明标准数据口径、必需字段与可选字段；只展示兼容的数据绑定。股票快照和指数序列即使字段相似也不能互换。
3. 金融资产 → 行情看板：添加已经绑定数据的小组件，选择尺寸、移动组件、移动编组、删除及保存。编组可保存到编组库，并以新的实例 ID 整体添加。

- 看板编辑提供拖动和等价的前后/上下移动按钮；触屏与键盘用户也能操作。删除编组前说明数据集不会删除，未保存布局支持撤销。
- “保存编组”保存可复用模板，“保存看板”保存整板配置，二者反馈必须区分。
- 组件只展示已保存数据；“刷新全部”和单组件刷新重读数据集，“同步最新数据”向上游取数，不能混为一件事。
- 看板使用单行紧凑工具栏，标题、数量和操作同层，不添加大标题描述区。浏览时提供刷新、添加、编辑布局；编辑时展示布局工具，仅有未保存修改时突出“保存看板”。退出编辑明确处理未保存修改。
- 名称与代码、数值与变化、标题与刷新状态各自紧密成组；组间留出明显间距。优先突出数据，不用等大的空白区分配视觉权重。
- 每个行情组件始终提供设置入口，支持刷新周期、尺寸、所属编组与适用的展示参数。设置即时预览，保存看板后持久化。超大尺寸独占一行，移动端自然铺满。
- 刷新支持手动、15 秒、30 秒、1 分钟、5 分钟、15 分钟、1 小时，默认 5 分钟。标题旁显示上次检查完成时间：绿色成功、橙色失败，刷新中显示旋转标记和文字。检查时间不能冒充交易日期；交易日期保留在来源栏。
- 云图参考 dapanyuntu.com 的深中性色、红绿阶梯和白字层级，固定 ±4% 映射上限，超出封顶。板块使用独立 24px 标题条、底部分隔与深色外边框，标题区域必须在布局时预留，不能覆盖个股。行业标题仍按成分等权涨跌着色。大块显示名称与涨跌幅，小块仅首字，微小块不显示文字；不使用荧光绿或随背景跳变的黑白文字。
- 大盘云图以市值或成交额编码面积，以固定涨跌幅色阶编码颜色，明确红涨绿跌。无有效面积值的记录不伪造面积。
- 云图按主题适配：深色保留深底红绿与白字；浅色、纸感主题使用各自中性浅底与红绿渐变、统一深色文字和较轻边界。标签按实际文字宽度缩小，优先完整名称，可用两行显示；仅在完整名称仍放不下时退化为首字。涨跌幅在名称之外有足够空间时显示，不挤占名称。
- 板块标题与内部股票共用一个蓝调外边框，标题下方仅用一条横线分隔，不给标题单独描四边框。外框在标题绘制后统一绘制，确保边缘连续。云图不用十字光标；命中股票时使用指针与轻微提亮描边，鼠标旁出现信息浮层。浮层使用顶层展示，避开视口边界且不拦截鼠标；点击固定，再点或 Esc 取消，滚动和离开窗口时清理。减少动态效果时禁用淡入动画。
- 行业观察注明 Tushare 行业分类与等权均值口径，不把聚合数值称为官方行业指数。指数卡片各自注明最近交易日期。
- 同步快照只读，可复制为可编辑数据；复制品保留 schema 与单位，但标注为本地数据。

## 加载与状态过渡

- 再次进入看板或刷新当前标签页时，先使用该标签页缓存的看板与已成功读取的数据，后台重新检查；交易日期和检查状态始终可见，失败保留旧图并提示。没有缓存才显示骨架。
- 骨架外层使用独立的 `loading-variant-*` 类，不与内部绝对定位图形共用类名；所有占位必须限制在看板内容区。
- 组件标题栏提供放大浏览入口，使用可关闭的模态浏览器，保留筛选、数据表和主题；Esc 关闭后焦点返回入口。看板组件高度统一为 180px 的整数倍（360/540/720），通用设置可选，内容超出时内部滚动。骨架、错误和刷新状态不能改变整卡高度；12px 布局细网格保留一致间隔。
- 指数以左侧点位与涨跌、右侧走势形成紧凑结构，不在卡片中展示成交量柱。量能只保留相对前条日线的放量/缩量比例，辅助日期和口径不得抢占主要信息的空间。
- 组件主体与放大浏览专注查看，允许临时筛选和排序；添加、移除及持久化内容管理集中在组件设置。自选股的搜索添加、已选列表与移除均放在设置内，空组件只提示设置入口。
- 所有组件设置统一为独立的“组件内容”和“通用设置”切换页，一次只显示一类设置。数据绑定、走势区间与专属选项放在内容页；尺寸、刷新周期、所属编组放在通用页。尺寸采用小、中、大、特大四个可键盘操作的图形单选项，展示真实占宽比例，不使用下拉框。
- 尺寸增加必须增加信息深度：自选股小尺寸显示收盘与涨跌，中尺寸增加成交额和 N 日走势，大及特大增加开高低和成交量；放大浏览使用完整字段。走势区间可选 5/10/20/60 个有行情交易日，标注实际覆盖与未复权属性。
- 指数用箭头、文字与涨跌幅共同显示方向，曲线沿用当日涨跌颜色并明确口径；量能以成交量对比前一条日线，缺失或零基数不能计算百分比。云图个股矩形不留白缝，以免小盘股被间隙吞没。
- 组件库支持名称、用途和英文标识的模糊搜索。自选股按名称或证券代码添加，关注列表随看板及编组模板保存，缺失行情必须明确提示。涨跌与成交排行使用绑定快照计算，不能伪造实时变化。

- 首次加载先呈现与最终图表同尺寸的骨架，不先把画布收成一行文字；金融组件与产业网络预留稳定高度。
- 内容使用短暂淡入过渡。骨架使用低对比度扫光；减少动态效果时停用扫光和位移动画。
- 刷新已有数据时保持旧图表、选择和容器，显示轻量更新提示。请求失败保留旧数据并显示失败状态。
- 网络图的新数据和新拓扑一起提交，不能将新节点数据与旧坐标混绘。重复刷新合并数据集请求。
- JSON 树按需展开，大数组分批显示，避免在读取全市场数据时一次创建数万控件。
